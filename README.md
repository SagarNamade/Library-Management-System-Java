# Library Management System

A Java-based Library Management System designed to demonstrate the **four pillars of Object-Oriented Programming (OOP)**: Encapsulation, Inheritance, Polymorphism, and Abstraction.

## 📌 Features

- Add library items
- Display all library items
- Search items by ID
- Search items by title
- Issue a library item
- Return a library item
- Display available items
- Track total number of library items
- Manage Books and Magazines

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Arrays
- Constructors
- Method Overriding
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
